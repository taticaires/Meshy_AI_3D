# Meshy AI 3D: Modelagem 3D com Inteligência Artificial

Material didático desenvolvido para o workshop de **Manufatura Aditiva** do Summit FMU, a convite do professor **Luciano Tadeu**.

O workshop abordou diferentes aspectos da manufatura aditiva. Enquanto o professor Luciano apresentou a história da impressão 3D, minha participação foi apresentar aos alunos possibilidades de criação de modelos tridimensionais com inteligência artificial, utilizando a ferramenta **Meshy AI**.

## Minha participação

Fui responsável por:

- Explorar os recursos do Meshy AI e realizar experimentos práticos.
- Criar exemplos de geração de modelos 3D com IA.
- Desenvolver este site como material didático de apoio ao workshop.
- Apresentar a ferramenta aos alunos, demonstrando possibilidades e limitações da modelagem 3D assistida por IA.

## O que o material apresenta

O site reúne experimentos com diferentes recursos da ferramenta, incluindo:

- **Text to 3D:** geração de modelos tridimensionais a partir de descrições em texto.
- **Image to 3D:** criação de modelos 3D a partir de imagens de referência.
- **Referências em múltiplos ângulos:** exploração do uso de diferentes vistas para orientar a geração.
- **Estilização:** experimentação com diferentes estilos visuais.

Os exemplos também registram observações sobre os resultados, permitindo discutir a fidelidade às referências, a interpretação dos comandos e as limitações encontradas.

## Objetivos e aprendizados

- Demonstrar aplicações de IA generativa na modelagem 3D.
- Explorar diferentes formas de interação com ferramentas de geração 3D.
- Analisar criticamente os resultados produzidos pela IA.
- Aproximar os alunos de novas possibilidades para criação de modelos aplicáveis à manufatura aditiva.
